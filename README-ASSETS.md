# README assets

## Replace the profile photo

The photo sits in the hero banner, in a circle beside the name. It is embedded inside `assets/hero-banner.svg`
(GitHub does not load separate image files from inside an SVG), made from `assets/profile-photo.jpg`.

To change it: save a new square photo over `assets/profile-photo.jpg`, then re-embed it in `hero-banner.svg`
(the `<image>` element's `href`, a base64 JPEG of about 480 x 480 px).

All SVGs except the photo you add are generated by `scripts/generate_assets.py` (run `python scripts/generate_assets.py .` from the repo root) so they share one palette, font stack and size set. Edit the script, not the SVGs. Palette:
abyss `#050A14`, panel `#0B1628`, line `#1E2D45`, text `#E6EDF7`, muted `#8A9BB5`, blue `#2F81F7`, cyan `#22D3EE`,
red `#F43F5E` (red marks only guard and approval steps).
